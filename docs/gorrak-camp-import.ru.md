# Лагерь Горрака: перенос макета в игру

Лагерь находится в Eastbrook Vale, основной двор около X=119, Z=45.
Две цельные палатки Emerald Camp Tent и цельный круглый шатёр заменяют
две старые условные палатки. Кроватей нет. У главаря стол, два стула
и сундук. Во дворе — костёр, кухня с треногой, заполненная стойка
оружия, запасы и поленница. Другие лагеря сохраняют военные палатки.

Четыре настоящих `supply_crate` перенесены к складу лагеря; два
оставлены на прежних местах. Всего по-прежнему шесть объектов,
их порядок и ID сохранены. Задания `q_supplies`, `q_bandits`,
`q_ringleader`, состав лагерей и порядок случайных бросков не меняются.
Декоративных копий квестовых ящиков поверх объектов нет.

Масштаб: игровой персонаж 2.6 единицы = 1.80 м. Входы имеют
проверенный просвет высотой 3.3 единицы. Коллизии измерены по ткани
и стойкам, без сплошного блока внутри. Для камеры используется
существующее выборочное скрытие мешающих частей, мебель сохраняется.

Грунт выровнен под полным пятном палаток, включая растяжки, с плавным
переходом шириной восемь единиц: узкий переход макета оказался слишком
крутым для физики персонажа на боковом выходе. Геометрия палаток не деформируется.
Исключения случайной растительности учитывают полные габариты.
Светлые плоскости дорог и схематические дорожки стенда не переносятся.

## Источники и повторная сборка

Исходный утверждённый стенд:
`D:/THE_GAME/artifacts/eastbrook-megakit-study/bandit-camp`.
Оригинальные архивы в `bible/models/ambient/constructions` неизменны.

```powershell
node scripts/assets/bandit_camp/import_study.mjs D:/THE_GAME/artifacts/eastbrook-megakit-study/bandit-camp
node scripts/assets/build_assets.mjs scripts/assets/specs/bandit_camp.json
$env:KTX_BIN = 'D:/THE_GAME/character-model-slice/tmp/ktx-software-4.4.2/bin'
$campFiles = (Get-ChildItem -LiteralPath public/models/bandit_camp -Filter *.glb).FullName
node scripts/assets/compress_glb_textures.mjs --jobs 2 @campFiles
node scripts/build_media_manifest.mjs generate
```

Импорт сохраняет исходную геометрию утверждённых производных моделей,
позы и материалы. Игровые модели используют meshopt и KTX2.
Координаты и палитры находятся в `src/sim/bandit_camp_data.json`,
происхождение — `scripts/assets/bandit_camp/provenance.json`.

## Проверки

Проверки входов и выхода, проходов, состава врагов и квестовых
объектов: `tests/bandit_camp.test.ts`, сиды 20061 и 42.
Артефакты сравнения с исходной игрой и браузерной проверки:
`D:/THE_GAME/artifacts/bandit-game-import-qa`.

Для ручной оценки: подход с юга, обход растяжек, все три входа,
доступ к сундуку и столу главаря, подбор четырёх складских ящиков,
бой и отступление. Автоматическая проверка не заменяет оценку
управления и композиции игроком.
